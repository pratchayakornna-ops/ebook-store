# 00. ภาพรวมของระบบ (System Overview)

## 📌 บทบาทผู้ใช้งานในระบบ (User Roles)
1. **ผู้เยี่ยมชมทั่วไป (Guest)**
   - ดูรายการหนังสือ ค้นหา และดูรายละเอียดหนังสือ
   - ต้องเข้าสู่ระบบก่อนสั่งซื้อหรือดาวน์โหลด
2. **สมาชิกทั่วไป (Customer / User)**
   - เลือกซื้อหนังสือ และใส่ตะกร้าสินค้า
   - ชำระเงิน แนบสลิปโอนเงิน
   - ดูสถานะคำสั่งซื้อ (รออนุมัติ / สำเร็จ / ปฏิเสธ)
   - เข้าอ่าน E-Book ออนไลน์ผ่านระบบเว็บรีดเดอร์
3. **ผู้ดูแลระบบ (Admin)**
   - ดูสถิติและ Dashboard ภาพรวมยอดขาย
   - เพิ่ม ลบ แก้ไข ข้อมูลหนังสือ และอัปโหลดไฟล์ PDF/รูปภาพ
   - ตรวจสอบสลิปการโอนเงิน และอนุมัติ/ปฏิเสธคำสั่งซื้อ

---

## 🏗️ โครงสร้างไฟล์ในระบบ (Project Structure)

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
| :--- | :--- |
| `config.php` | เชื่อมต่อฐานข้อมูล MySQL และฟังก์ชันส่วนกลาง (`isLoggedIn`, `isAdmin`, `getCartCount`) |
| `index.php` | หน้าร้านค้าหลัก แสดงรายการหนังสือ หมวดหมู่ และการค้นหา |
| `book_detail.php` | แสดงรายละเอียดของหนังสือแต่ละเล่ม |
| `cart.php` | หน้าตะกร้าสินค้า เพิ่ม/ลด/ลบ รายการสั่งซื้อ |
| `checkout.php` | หน้าสรุปยอดเงิน สแกน QR Code โอนเงิน และแนบสลิปหลักฐาน |
| `orders.php` | ประวัติการสั่งซื้อของลูกค้า |
| `my_books.php` | ชั้นหนังสือส่วนตัวของลูกค้า (เฉพาะเล่มที่อนุมัติแล้ว) |
| `read.php` | ตัวเปิดอ่านหนังสือออนไลน์ (Online PDF Reader) |
| `admin_dashboard.php` | สรุปยอดขาย และสถิติต่างๆ สำหรับ Admin |
| `admin_books.php` | จัดการหนังสือทั้งหมด |
| `add_book.php` / `edit_book.php` | หน้าเพิ่มและแก้ไขข้อมูลหนังสือ |
| `admin_orders.php` | หน้าตรวจสอบสลิปและอนุมัติคำสั่งซื้อ |
| `uploads/` | โฟลเดอร์จัดเก็บรูปปกหนังสือ สลิปโอนเงิน และไฟล์ PDF |
| `docs/` | โฟลเดอร์จัดเก็บเอกสารอธิบายการทำงานของแต่ละขั้นตอน |
